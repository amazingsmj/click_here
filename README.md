# Pour Emilia - Valentine's Day 2026 🌹

A romantic, cosmic-themed web experience created for Emilia.

## ✨ Features

- **Cosmic Atmosphere**: A procedurally generated starfield with shooting stars and a shifting nebula background.
- **Lyrics-Style Poem**: An elegant poem displayed with a "lyrics-mode" focus effect. The text scrolls automatically at a comfortable reading pace, highlighting the current verse while others stay soft and blurred.
- **Interactive Heart**: A "Click here" button that triggers a transformation of the starfield into a pulsing heart of pink stars.
- **Musical Immersion**: Features a curated soundtrack (*Another Love - Instrumental*) that syncs with the experience.

## 🚀 How to Run

Simply open `index.html` in any modern web browser.

> [!NOTE]
> Most browsers block audio from playing automatically. The experience is designed to start the music and the auto-scroll on the first click anywhere on the page if autoplay is prevented.

## 🛠️ Built With

- **HTML5 Canvas**: For the particle engine and heart animation.
- **Vanilla JavaScript**: For the auto-scroll logic and interaction management.
- **CSS3**: For the Glassmorphism UI and fluid typography.
